# GiftCraft – Corporate Gifting Website

## Project Structure

```
gift/
├── index.html              ← Home 1 (General Services)
├── home2.html              ← Home 2 (Niche-Specific Gifting)
├── about.html              ← About Us
├── services.html           ← Services
├── service-details.html    ← Service Details
├── blog.html               ← Blog
├── blog-details.html       ← Blog Details
├── contact.html            ← Contact Us
├── 404.html                ← 404 Error
├── coming-soon.html        ← Coming Soon / Maintenance
└── assets/
    ├── css/
    │   └── style.css       ← Main stylesheet
    └── js/
        └── main.js         ← Main JavaScript
```

## Tech Stack
- Bootstrap 5.3
- Bootstrap Icons 1.11
- AOS (Animate On Scroll)
- Google Fonts: Manrope + Plus Jakarta Sans

## Features
- Dark/Light mode toggle
- RTL language support
- Sticky navbar with scroll effect
- Mobile-first responsive (320px–1440px+)
- Scroll animations (AOS + custom)
- Animated counters
- Form validation
- File upload zone (drag & drop)
- Countdown timer
- Gift category filter
- Back-to-top button
